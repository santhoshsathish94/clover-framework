# Curiosity & Autonomous Developmental Learning — 13-Paper Executable Research & Context Index

 Following the Clover principle (**"Only work will show real understanding, not reading — record each one through separate context files, step by step, without prejudging where each one should go in Clover"**), all 13 primary research papers on infant curiosity, intrinsic motivation, active sampling, and developmental robotics have been:
1. Downloaded and extracted as primary text in [research/curiosity-and-developmental-learning/papers_text/](../../../research/curiosity-and-developmental-learning/papers_text/),
2. Implemented as standalone, reproducible mathematical and algorithmic experiments (`01`–`13`) that test both the authors' core claims and their structural breakdown boundaries, and
3. Recorded in **13 separate Context files** in [docs/runtime-context/curiosity-and-developmental-learning/](.).
