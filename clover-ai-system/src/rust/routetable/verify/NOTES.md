# routetable differential driver (agent C1, 2026-10-22)

Written by the C1 agent as a handoff; correct or delete it as you see fit.

**What it is.** `diff_driver.cpp` dlopens a reference and a candidate `libroutetable*.so` (RTLD_NOW|RTLD_LOCAL, separate tables) and compares them value by value. At most one table per library is live (sessions load, compare, free). It does not modify the Rust crate, `ref/` or the header.

**Rerun (box `gpu`).** `ssh gpu 'cd ~/rustmig/routetable/verify && ./build.sh && ./run.sh [CANDIDATE.so]'` (env `REF`, `JOBS`, `OUT`; extra driver options after the candidate: `--only R1,R2,R3,R4 --scale F --keep-going --trace FILE`). Output: `out/run-<time>/` with `units.log` (raw: `BEGIN scen seed` / `UNIT scen seed cmp chk nu files bytes PASS|FAIL calls= exp= cnt= neg= nuhit= feat=`), `stdout.txt`, `r4-cases.log`, `fail/` (first-difference report + the input file), `work/*.err` (worker stderr). `./count.sh OUTDIR` recounts from `units.log` with awk. `./asan.sh` rebuilds the reference into `ref-asan/` with `-fsanitize=address,undefined` (recoverable UBSan) and runs everything against the normal Rust build with libasan preloaded. `./md5.sh` hashes everything the run depends on. The driver stops scheduling at the first FAIL/CRASH (use `--keep-going` to continue) and prints seed, hex dump of the input (first 384 / last 96 bytes), both results and the last 12 operations.

**Counting.** comparison (cmp) = one reference-vs-candidate equality on a scalar (`rt_calls`, `rt_layer`, each list length, each list element, each `rt_next_use` result) or, in R4, one of exit status / stdout / stderr. chk = single-library checks (non-NULL pointer when length > 0; R4 contract text). `--flip N` perturbs the candidate's N-th compared value of every unit: a plumbing check that the comparison and reporting path fires (run with N=30, 1500000, and R4 with 31; each failed with a located report). It is not a mutation control.

**Scenarios.** R1 well-formed traces (400 seeds, 3-4 sessions each: load, compare table, engine-like operation mix, compare again, free; reload of the same file; same file with another `experts`; a different file; `experts` in {896, 1, 7, 100000}). R2 byte fuzzer (20000 seeds; random bytes, token streams with numbers around 2^31/2^63, mutated well-formed lines, crafted fragments; empty / only-newline / no-final-newline files). R3 the real `~/k3gpu/results/p1d.trace` (read only) with the engine's access pattern (current = i, look-ahead calls i..i+92, rc_plan_vq form, repeats, backward pass, reload, other `experts`; 9 seeds; seeds 6-8 use experts 7, 1, 100000). R4 child processes per library (fixed 20 cases + 400 random unopenable paths).

**Independent cross-checks done.** R3 tables loaded: 27 = 9 seeds x 3 sessions, calls 151524 = 27 x 5612 and experts 3625047 = 27 x 134261 where 134261 = (sum of fields of p1d.trace, 145485) - 2 x 5612 by `awk` on the file. Comparisons per scenario recounted from `units.log` with the driver's summary, awk (`count.sh`) and PowerShell: equal.

**Not covered.** See the final report of the run: `rt_load` twice without `rt_free`, NULL `t` / `path`, `rt_free(NULL)`, index >= `rt_calls`, `experts` <= 0, threads, files > 2 GB or > 2^31 calls, a read error in the middle of a real file, mutated candidates (later step). R4 is a small case list (1260 comparisons), not a volume scenario.

**Finding.** The reference `ekey` (`layer * g_experts_rt + e`, `routetable_ref.cpp:12`, same in the engine's decode.cuh:201) is signed `int` arithmetic: UBSan reports overflow in R2 (fuzzed layers / experts) only; R1, R3, R4: none. The Rust crate wraps; the two agreed on every key tested. Unreachable in the engine (layer <= 92, experts 896).
