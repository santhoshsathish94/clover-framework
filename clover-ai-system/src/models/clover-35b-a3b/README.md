# Clover-35B-A3B Coordinator Backend (`clover-ai-system/src/models/clover-35b-a3b/`)

In **Clover v6.0**, `"clover-35b-a3b"` serves as the primary **35B-total / 3B-active Mixture-of-Experts Coordinator Brain** (`Qwen3.6-35B-A3B + Clover-Harness-LoRA` packed in `HG4-16R-OP` at `17.4 GB`), running interactively on a **single `24 GB` GPU (`35.8 tok/s`)** behind the **4-Part Steerable Clover Harness** ([`../../tools/hg4-fusion-gateway/`](../../tools/hg4-fusion-gateway/) and [`../../../studio/clover/clover_v6_system.py`](../../../studio/clover/clover_v6_system.py)):

- **`HG4-16R-OP` Compression & Kernel (`clover35b_hg4_engine.c`, `pack_clover35b_hg4.py`):** Shrinks `70.0 GB` BF16 weights to `17.4 GB` (`86/86` deterministic token match) using Block-16 Walsh-Hadamard outlier rotation + group-quantized 4-bit LUT16 kernels so the full 40-layer, 256-expert (`top-8`) model + `32k` KV cache (`~20.2 GB` resident) stays pinned in VRAM on `1× RTX 3090 / 4090 / L4 / A10G`.
- **Interactive Hardware Gate in Clover AI Studio:** Automatically verified via multi-token live `/v1/chat/completions` probes (`>= 24 GB` GPU VRAM required for interactive speed; skipped cleanly on CPU-only devices).
- **Historical `v5` Precomputed Trunk Artifacts:** Earlier `DiffuSpace/Clover-35B-A3B-Preview` `CLV35TRK` / `CLV35BD1` and `HybridAgent`/`NCM` experiments (`clover_35b_hybrid_ncm.py`, `verify_clover_35b_clover_integration.py`) remain preserved in this folder for reproducibility.
