# DiffuSpace Clover-35B-A3B (`35B-A3B`) Model Backend (`clover-ai-system/src/models/clover-35b-a3b/`)

This folder implements the precomputed trunk (`CLV35TRK`), composed operator (`CLV35OP1` / `operator.bin`), Bidirectional Gated DeltaNet preview container (`CLV35BD1` / `bd_gdn.bin`), trunk pruner, direct routed-expert store (`experts.direct` & 4-bit planar group-64 `experts.4bit.direct` with `moe_block_coreset_top_p = 0.9` block coreset selection), `HybridAgent` (`Clover35BNativeHybridLink` $d=2048$), `11-Level NCM` (`248,320`-Vocab VQ-VAE + `Clover35BComboBridge` + `Clover35BExpertBridge`), and selectable `JEPA` trunk (`jepa-trunk-0`) for **DiffuSpace's `Clover-35B-A3B-Preview`** (`Diffuspace/Clover-35B-A3B-Preview` & `Diffuspace/Clover-35B-A3B-Preview-GGUF`, Apache-2.0, `35B` total / `3B` active parameters, `40` layers, `D_model = 2048`, `V = 248,320`, `128K` context window, `block_size = 32` LowConfidence block diffusion):

- **40-Layer 3:1 Hybrid Schedule (`D_model = 2048`, `V = 248,320`):**
  - `30` **Bidirectional Gated DeltaNet (`BD-GDN`)** `linear_attention` layers (`layers 0, 1, 2, 4, 5, 6, ...`): `16` key heads $\times 128$ (`2048`), `32` value heads $\times 128$ (`4096`), `channels = 8192`, `conv1d` kernel width `4` + bidirectional preview `conv_right_weight [8192, 1, 3]` and `bd_softmax_{logit_scale, history_bias, history_c} [32]` packed in `bd_gdn.bin` (`CLV35BD1`).
  - `10` **Gated Full-Attention (`Gated GQA`)** `full_attention` layers (`layers 3, 7, 11, 15, 19, 23, 27, 31, 35, 39` 0-indexed): `16` query heads $\times 256$ with fused sigmoid output gate (`q_proj [8192, 2048]`), `2` KV heads $\times 256$, zero-centered `q_norm` & `k_norm`, `partial_rotary_factor = 0.25` (`64` rotary dims, `rope_theta = 10,000,000`).
  - **256-Expert MoE with Block Coreset Selection + Shared Expert (all 40 layers):** `256` routed SwiGLU experts (`top-8`, `moe_intermediate_size = 512`, `moe_block_coreset_top_p = 0.9`) + `1` shared SwiGLU expert (`512` intermediate) gated by `sigmoid(shared_expert_gate(x))`.
