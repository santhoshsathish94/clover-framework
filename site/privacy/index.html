Privacy Policy · Clover AI Studio (`ai.clover.studio` & `SanthoshNarayanan.CloverAIStudio`) · Effective November 5, 2026

Nothing leaves your device unless you allow it.

Clover AI Studio runs its AI models, semantic parser, memory graph, personal learning, and tools directly on your phone or laptop. There are no analytics SDKs, no telemetry servers, no advertising identifiers, and no cloud accounts required.

Where data is stored ↓ How data is logged ↓ Governance Rules →

Section 1 of 6 · Zero Off-Device Collection

100% On-Device by Default

When you type a message, attach a photo, record your voice, or analyze a document in Clover AI Studio, all processing happens locally on your own hardware over a loopback connection (127.0.0.1).

No Telemetry

Zero Analytics or Tracking

Clover AI Studio contains no third-party analytics, crash reporters, behavioral trackers, or advertising SDKs. We do not know who you are, what you ask Clover, or when you use the app.

Local Inference

Models Run on Your Hardware

The multimodal language model (LFM3-Omni-2B), semantic interface (CSI), and knowledge graph run on your device's GPU or CPU. Prompts and answers are never sent to external AI servers unless you explicitly add and select a remote model.

Explicit Permissions

You Control Every Capability

Internet search, Python execution, terminal commands, file access, and memory each have an independent Allow / Ask / Off switch in Settings → Advanced → Permissions.

Section 2 of 6 · Exact Storage Locations

Where Your Data Is Stored on Your Device

Clover AI Studio stores all state inside a single base directory on your device. You can view these exact paths at any time in Settings → Storage.

Windows 10 & 11 (`CloverAIStudio.exe`)

%USERPROFILE%\CloverAI\

All files reside in your Windows user profile folder (for example, C:\Users\<you>\CloverAI\):

  • clover-ai-studio\ — Local Git repository holding conversations, execution logs, outcomes, learned memory, and settings.
  • media\ — Photos, voice recordings, videos, charts, and attached documents (media\documents\). Kept outside the Git repository.
  • vault\ — Optional API keys and tokens encrypted with Windows DPAPI (CryptProtectData) bound to your Windows user login.
  • models\ — Local GGUF model weights verified against pinned SHA-256 hashes.
Android (`ai.clover.studio`)

/data/user/0/ai.clover.studio/files/CloverAI/

All files reside inside Android's private application sandbox with android:allowBackup="false" so other apps and cloud backups cannot read them:

  • clover-ai-studio/ — Local on-device Git repository holding your chats, execution logs, outcomes, memory graph, and settings.
  • media/ — Attached images, audio clips, videos, and documents. Kept outside the Git repository so you can clear them in one tap.
  • vault/ — Optional API keys encrypted at rest with AES-GCM using a local device-bound key (0600 permissions).
  • models/ — On-device LFM3-Omni-2B GGUF weights and vision/audio projector.

Section 3 of 6 · Local Logging Architecture

How Data Is Logged Inside Your Local Repository

To give both you and Clover an auditable memory on your device, Clover logs each turn into plain-text and JSON-Lines files inside your local clover-ai-studio/ folder. Nothing in this repository ever leaves your device unless you explicitly connect your own private GitHub repository.

sessions/YYYY-MM/<chat_id>.jsonl
Stores only the conversation turns: your message text, attachment filenames, and Clover's final answer (one JSON object per line, with timestamp and turn number).
execution/YYYY-MM-DD.log
Plain-text step-by-step log of how each turn ran on your device: what the semantic layer understood, which context layers (memory, knowledge graph, workspace, earlier chats) were consulted, which tools were offered or called, whether permission was granted or denied, and turn duration. Binary attachments are never written here.
outcomes/YYYY-MM.jsonl
Records whether each turn completed or was stopped, whether each tool call succeeded or failed, whether the S3 code compiler check passed, and your explicit or implicit feedback (such as clicking Helpful or Try again).
growth/knowledge/ & growth/notes/
Holds facts you explicitly ask Clover to remember, verified lessons from corrected answers, and short idle-time exchange notes used by Layer S2 to recall earlier conversations on your device.
growth/personal/
Personal Process Learning (PPL) records of how you phrase requests and how you prefer answers formatted. Stored strictly on your device and never exported.
config/<device>/
Stores your non-secret preferences: active model/engine choice (settings.json), tool permission states (permissions.json), search provider name (search.json), and workspace paths (workspaces.json).
Automatic Secret Redaction

Secrets Never Reach the Logs

Before any text is written to sessions/, execution/, outcomes/, or growth/, clover_repo.redact() scans and replaces credential patterns—including GitHub tokens (ghp_..., github_pat_...), API keys (sk-..., tvly-..., AIza...), AWS keys (AKIA...), Slack tokens (xox...), and private keys—with [redacted ...].

Code-Enforced Sandboxing

Tools Cannot Read the Vault or Tamper with Logs

In paths.py, read_blocked() and write_blocked() enforce in code that the AI model's file and shell tools cannot read vault/ and cannot modify clover-ai-studio/ records, settings, or AGENTS.md.

Section 4 of 6 · Optional User-Initiated Connections

When Network Connections Happen

Clover AI Studio makes network connections only when you initiate one of the following actions:

1 · First-Launch Model Setup

Verified Open-Weight Downloads

On first start, Clover downloads the open-weight LFM3-Omni-2B model files directly from Hugging Face (and, on Windows, the standalone Python runtime and dependencies), verifying every file against its pinned SHA-256 checksum before use.

2 · Web Search & URL Reading

Controlled by Your Internet Permission

When you ask Clover to search the web or open a URL—and your Internet permission in Settings → Advanced → Permissions is set to Allow or approved via Ask—your search query or URL request is sent over HTTPS directly to your selected search provider (DuckDuckGo, Brave, Tavily, or Serper) or target website.

3 · Private GitHub Backup (Optional)

Your Own Private Repository

If you choose to sign in under Settings → GitHub account, Clover syncs your local clover-ai-studio/ Git repository over HTTPS to a private clover-memory repository in your own GitHub account. Your vault/ and media/ folders are never uploaded.

4 · Collective Problem-Solving Learning (Opt-In)

Off by Default · Google OIDC & Zero Verbatim Text

Collective Problem-Solving Learning (CPSL) in Settings → Learning & Growth is off by default. When opted in, it authenticates via stateless Google OpenID Connect (sub claim only; no emails, passwords, or OAuth access tokens stored) and strips all user text, file paths, numbers, and identifiers locally before uploading closed-vocabulary candidate strategies or downloading Ed25519-signed shared-core rules.

Section 5 of 6 · OS Permissions

Android & Windows System Permissions

Microphone (RECORD_AUDIO)
Used only when you hold the Send button to record a voice message. Audio is converted to 16 kHz WAV in memory and processed by the local model on your device.
Foreground Service (FOREGROUND_SERVICE_SPECIAL_USE)
Used on Android to keep the local llama-server inference engine and initial model download alive with a visible status notification ("Clover runs on this phone") and an immediate Stop button while an answer is being generated.
Network (INTERNET)
Used for local loopback communication (127.0.0.1) between the Studio UI and the embedded local server, initial model download from Hugging Face, and optional user-approved web search or GitHub sync. Cleartext traffic to external hosts is disabled in network_security_config.xml.

Section 6 of 6 · Data Deletion & Contact

How to Delete Your Data at Any Time

Because all data resides on your own device, you have immediate, permanent control over deleting any or all of it without contacting us:

In-App Controls

Granular One-Tap Deletion

  • Delete a single conversation: Click the trash icon next to any chat in the sidebar.
  • Delete all conversations: Open Settings → Storage → Delete all chats.
  • Delete all photos, audio, video & documents: Open Settings → Storage → Clear attachments.
  • Forget all personal learning (PPL): Open Settings → Advanced → Clover layers → What Clover learned → Forget everything Clover learned about you.
Full Removal & Contact

Complete Uninstall & Support

Uninstalling Clover AI Studio on Android (or running Uninstall / deleting %USERPROFILE%\CloverAI on Windows) permanently removes the local repository, attachments, encrypted vault, and downloaded models from your device.
