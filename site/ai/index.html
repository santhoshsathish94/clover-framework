Clover AI live server is currently offline

The live Clover AI server endpoint is currently offline for maintenance. As soon as a Clover AI server (https://api.cloverframework.com or local http://127.0.0.1:8765) is online, this page automatically switches to the interactive Clover AI interface.

Keeping a dedicated multi-GPU / high-memory machine running 24/7 for a free public web endpoint costs more than an independent, self-funded open-source project can carry continuously. Rather than leaving a broken chat box up when the server is powered down, this page checks server availability automatically and displays this notice while offline.
