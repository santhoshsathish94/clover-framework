Status · Maintenance

Clover AI live server is currently offline

The rented 8 × NVIDIA RTX 3090 GPU server window used to build and verify Clover AI v4 (v4.0.0) is now complete, so the live public chat endpoint is down for maintenance. We will spin the live server back up once we get funded.

Keeping a 192 GiB multi-GPU machine running 24/7 for a free public web endpoint costs more than an independent, self-funded open-source project can carry continuously. Rather than leaving a broken chat box up when the GPU box is powered down, this page states the status plainly.

Everything built on the server is open and reproducible

Before the GPU server time ended, we wiped the machine to a clean state, bootstrapped it fresh from GitHub and Hugging Face, and verified the complete 7-layer Clover AI v4 stack across the 70-task evaluation suite (33/70 → 57/70 → 70/70).
