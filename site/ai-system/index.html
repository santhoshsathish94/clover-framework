The simpler v6.0 4-Part Clover System

Every self-hosted Clover deployment runs the same four-part steerable loop directly from open source (clover-ai-system/).

Part 1 · AGENTS.md

1. Human Steering & Epistemic Boundaries

Enforces Context → Direction → Execution → Outcome → Growth in code, halts destructive or stagnant runs with STOP_AND_ASK, and applies a Tier-0 tool-exposure gate so small 2B models are never flooded with unrequested planning schemas.

Part 2 · mcp.json

2. Computed 0B Specialists First

Never asks neural weights to guess what an algorithm computes: built-in x-cruncher big-integer arithmetic (A×B, A^B past 6,000+ digits, N!, BBP hexadecimal π), a 0B Periodogram + Split-Conformal forecaster (<110 ms CPU), a 0B Defeasible Rule Resolver, and AST code checks — plus optional HG4 GPU specialists over MCP 2.0.

Part 3 · <task_id>.md

3. Durable Task Context & Private Git Memory

Writes human-readable <task_id>.md context records and stores sessions, verified outcomes, and encrypted credentials locally on your own device (Windows DPAPI / Android KeyStore) with optional sync to your own private GitHub repository (Privacy Policy).

Part 4 · Todo & Telemetry

4. Prerequisite-Gated Todo & Live Metrics Ledger

Tracks multi-step dependencies in SQLite (todos + todo_deps) and records live telemetry (GET /api/clover/metrics): which models and tools are actually used vs. idle, measured decode tok/s (p50/p95/max), cycle retries, and Cycle-2 self-repair signals.

Set up one model — or the full Clover AI System — on your own hardware

Inside Settings → Model → Clover System Setup (and right from first launch via Choose models / Use server), you can select a single model, a custom subset, or the complete Clover AI System across your device and any GPU servers you provide.

Honest interactive hardware gate: Small models and 0B computed tools run interactively on any phone, laptop, or CPU server with zero GPUs. Big models require GPUs to run at interactive speed — if a machine is CPU-only or lacks the required GPU VRAM, Studio automatically skips those models and tells you the exact minimum server needed rather than letting a model crawl at <1 decode tok/s.

Myth 2 & Myth 3 Applied · Bandwidth Multiplies Across Small Machines

One giant GPU server does not give faster decoding — multiple smaller right-sized GPUs do

Memory size (GB) only decides whether a model fits; decoding speed comes strictly from memory-highway bandwidth (GB/s). Paying for one giant 80 GB–192 GB enterprise server to run a 17.2 GiB model adds ~0 tok/s, and putting four workers behind one shared CPU bus stalls at 16.0 tok/s†. By contrast, four right-sized 24 GB RTX 3090 cards bring four independent 936 GB/s memory highways (3,744 GB/s aggregate) — delivering 4 × 58.5 = 234.1 decode tok/s† (14.6× faster) across four parallel streams (4 × 168.4 = 673.4 tok/s on 4× 4090 JSON) and pooling four buses together to decode 58.2 GiB Nemotron 120B at 172.2 tok/s on 4× 4090 MTP JSON / 38.4 tok/s on 4× 3090 CLI† (see Myth 1, 2 & 3 proofs →).

Full multi-user batching & clubbing, honest per-user reporting: Every Clover GPU server supports multiple concurrent users, dynamic batching (reusing one VRAM weight read across active requests), and T = 0 request clubbing in gateway.py — while the table below reports true per-user autoregressive decode (batch = 1) with explicit GPU provenance (RTX 3090 vs. RTX 4090). How k3 and the RTX 3090 servers ran as one complete system

Instead of renting one giant monolithic supercomputer, Clover connected one permanent CPU coordinator hub (k3) to modular, right-sized 24 GB RTX 3090 GPU petals over 4 Bytes/token binary sockets (tsock://).

Step 1 · 0 ms on k3 CPU

Compute Deterministically Before Touching Any GPU

Every request hits k3 first. High-risk destructive commands trigger STOP_AND_ASK; exact integer/factorial/π math runs in x-cruncher (<1 ms); periodic time-series run in the 0B Periodogram+Conformal solver (<110 ms); policy overrides run in the 0B Defeasible Resolver — consuming zero GPU tokens.

Step 2 · tsock:// + Verifier Cascade

Right-Sized RTX 3090 Petals & Escalation

Each RTX 3090 server registers into k3’s PetalRegistry over 4 B/tok tsock:// sockets with T = 0 request clubbing. Qwen3.6-35B-A3B + LoRA handles coordination and invokes Goedel-32B or Boltz-2 via mcp.json; only if an AST, unit-test, or Lean 4 check still fails after Cycle-2 repair does k3 escalate to Nemotron 120B or Kimi 2.8T.

Ambitious Research · Next Clover Milestone

Five Senses, One Brain — Less Model, More Deterministic Libraries

Humans do not grow billions of extra neurons to calculate a 100-digit product — we have five senses, one brain that coordinates them, and we learn to use tools.

Today’s AI industry tries to cram every skill — vision, speech, exact arithmetic, syntax, physics, and tool calling — into one giant neural network trained to predict everything. Our next ambitious research milestone asks the opposite question: how small and reliable can an AI system become when deterministic libraries handle what can be computed, five focused sensory modules perceive the world, and one compact brain coordinates them all?

Ambitious Research · Senses & Libraries

1. Five Senses Built on Libraries First

Pair proven deterministic libraries (OpenCV/layout geometry, signal DSP, compilers, x-cruncher, Lean 4, conformal statistics) with thin purpose-trained sensory encoders — multilingual ear & voice adapters (IndicConformer + Freeze-Omni) and document/scene vision (PaddleOCR-VL) — so neurons never guess what a library already computes.

Ambitious Research · Foveated JEPA & One Brain

2. Foveated Attention & One Compact Coordinator

Even though human eyes face an entire room, we focus sharply on only a few details that matter. Using 3-signal foveated JEPA surprise cropping, Dual-Channel Tool-NCM (separating conceptual intent from exact symbol tapes), and gradual self-improving Clover cycles (Cycles 1 → 1,000,000+), we aim to train a compact Clover-Seed coordinator brain from scratch.

This research is openly recorded as a long-horizon, step-by-step plan in one-brain-five-senses-research-context.md — clearly separated from what ships and runs today in v6.0.0, and verified one Clover cycle at a time (reproduce today’s 6-myth proofs yourself →).
