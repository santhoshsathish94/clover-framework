# Research

Research informs Clover; it is not automatically framework doctrine or a runnable product.
Historical records retain the measurements, corrections, and failed attempts that produced
later conclusions. A document's status describes its role, not whether its outcome was favorable.

For maintained framework guidance, use [docs](../docs/README.md). For the executable
single-machine reference, use [Clover-K3](https://github.com/santhoshsathish94/clover-framework/blob/013cbc89a99ba506c567b081613049ac76d405a6/clover-k3/README.md). For reported real work,
use [case studies](../docs/case-studies/README.md). The current seven-layer Clover AI version is
described in [Clover AI v4](../docs/reference/release-v4.md).

New research should state its question, evidence environment and date, what was observed,
what remains unknown, and which current summary it informs. Preserve historical evidence;
do not update an old run's claims to make it look like a later run.
