## E2: Exact Algebraic Equivalence of TD(1) and Widrow-Hoff (Theorem 1, pp. 13-15) & Eligibility Trace Recursion (Eq. 3-4, pp. 15-16)
- Prediction 2.1 (Theorem 1, p. 15): For any observation-outcome sequence x_1, ..., x_m, z and any weight vector w and feature matrix X (both tabular unit-basis and arbitrary dense features), the per-sequence weight update sum_{t=1}^m alpha * (P_{t+1} - P_t) * sum_{k=1}^t grad_w P_k of linear TD(1) (Eq. 3) will equal the Widrow-Hoff supervised update sum_{t=1}^m alpha * (z - P_t) * grad_w P_t (Eq. 2) to within floating-point precision (< 1e-14).
- Prediction 2.2 (Incremental Eligibility Trace Eq. 4): Computing e_{t+1} = grad_w P_{t+1} + lambda * e_t incrementally in O(d) memory will match the explicit sum_{k=1}^{t+1} lambda^{t+1-k} grad_w P_k across all lambda in [0, 1] to < 1e-15.
- Prediction 2.3 (Negative control — intra-sequence weight drift, Section 5.2 p. 35): If w is updated inside a sequence after every step t using P_t = P(x_t, w_{t-1}) instead of off-line per-sequence accumulation (Eq. 1), TD(1) and Widrow-Hoff are NO LONGER algebraically equal (max difference > 1e-3), because P_{t+1} - P_t conflates state transition changes with intra-sequence weight changes (p. 35).

## E4: Why TD(0) Beats Supervised Learning — The "Bad State" Game Example (Figure 1, pp. 17-18), Cumulative Steps Prediction (Section 5.1, pp. 33-34), and Non-Markovian Counterexample (p. 18)
- Prediction 4.1 (Figure 1 Game-Playing Example, pp. 17-18): In the Markov process where "Bad" leads to Win (z=1) 10% of the time and Loss (z=0) 90% of the time (true E[z|Bad] = 0.10), and a "Novel" state transitions deterministically to "Bad" (true E[z|Novel] = 0.10) on a single lucky episode `Novel -> Bad -> Win (z=1)`, Widrow-Hoff TD(1) assigns the novel state toward 1.0 (converging under repeated presentations to E_WH[Novel] = 1.0, error = 0.90!), whereas TD(0) bootstraps off Bad's learned value (~0.10 + small update), converging under repeated presentations to the exact empirical Markov rate (n_wins / n_bad_trials, error < 0.05).
- Prediction 4.2 (Non-Markovian Counterexample, p. 18): When the process violates the Markov assumption ("Suppose the bad state is usually followed by defeats except when it is preceded by the novel state, in which case it always leads to a victory", p. 18) and the state representation collapses both paths into the same feature x_{Bad}, TD(0) suffers state aliasing and predicts ~0.18 for Novel (error > 0.80), whereas TD(1) (Monte Carlo / Widrow-Hoff) remains unbiased and converges to 1.00 for Novel!
- Prediction 4.3 (Cumulative Outcomes TD(lambda), Section 5.1 pp. 33-34): Using cumulative TD(0) with step cost c_{t+1} = 1 and P_{m+1} = 0 on the 5-state random walk will converge to the exact expected number of steps to absorption [(I - Q)^{-1} 1] = (5, 8, 9, 8, 5) for states (B, C, D, E, F).
