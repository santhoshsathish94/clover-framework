# Clover AI v4

**Status:** Release candidate documentation for the current seven-layer Clover AI system.  
**Scope:** The existing Clover AI implementation; the next research experiment is tracked separately as [Observe](../research/observe/README.md).

## What v4 represents

Clover AI v4 is the current seven-layer system described in the repository. Its seven layers cover:

1. Governance and discernment.
2. File-based memory and relational knowledge graph.
3. Ontology-guided neuro-symbolic GraphRAG and symbolic verification.
4. HybridAgent reasoning and tools.
5. On-the-fly Python and Rust generative compilation.
6. The Kimi K3 CPU/GPU engine and validated Rust host path.
7. Parallel Next-Concept Modeling and web/VS Code agent surfaces.

The authoritative implementation details, supported claims, evidence, and limitations remain in the root [README](../README.md), [Clover-Kimi-K3 documentation](../clover-kimi-k3/README.md), [Foundations-to-Clover & 70-Task Evaluation Context](../clover-kimi-k3/docs/clover-foundations-to-clover-gpu-context.md), and the committed benchmark bundles under [`benchmarks/results/1936d4eb0d53/gpu/`](../benchmarks/results/1936d4eb0d53/gpu/). A version label does not replace those evidence records.

## Verified v4 baseline and boundaries

1. **Zero-state reproducible setup (`1936d4eb0d53`):**
   - Verified on the `8 × NVIDIA RTX 3090` server (`gpu`) after wiping all legacy directories under `/home/usergpu/` and bootstrapping fresh from GitHub (`santhoshsathish94/clover-framework`) and Hugging Face (`Santhoshsathish94/clover-kimi-k3`).
2. **What the 70-task head-to-head and 3-arm ablation prove ([`clover_70_ablation_report.json`](../benchmarks/results/1936d4eb0d53/gpu/clover_70_ablation_report.json), [`frontier_70_scored_report.json`](../benchmarks/results/1936d4eb0d53/gpu/frontier_70_scored_report.json)):**
   - **Clover's underlying model alone (`Arm 0`, no Clover mechanisms):** `33 / 70` (`47.14%` pass rate, `234.0 GPU-s / solved task`).
   - **Adding Tool Orchestration (`<python>`, `<search>`) & Generative Compilation (`Arm 1`):** `57 / 70` (`81.43%` pass rate, `+24 tasks`, `142.5 GPU-s / solved task`).
   - **Adding Ontology GraphRAG & Persistent Memory Graph (`Arm 2`, Full Clover v4):** `70 / 70` (`100.00%` pass rate, `99.08%` mean score, `+37 tasks` total over `Arm 0`, `114.5 GPU-s / solved task`).
   - **Head-to-head against standalone frontier reference models on the exact same 70 prompts:** On the 58 public/general tasks (zero tools), standalone **Claude Opus 5.5** (`57 / 58 = 98.28%`) and **GPT-6 Astra** (`56 / 58 = 96.55%`) are already near-perfect in-weights (vs. `30 / 58 = 51.72%` for Clover's raw model alone), and rightly abstain on private organizational ontology/memory records not in their prompt (`65 / 70 = 92.86%` and `63 / 70 = 90.00%` overall). Clover's value is the `+52.86 pp` system lift around a local open-weights model, not a claim that its raw model outperforms frontier models on full public leaderboards.
3. **CPU vs. GPU scope boundary:**
   - The full 70-task suite and 3-arm ablation were executed on the `8 × RTX 3090` GPU server (`gpu`). On the single-workstation CPU host (`k3`), the bit-identical C engine (`run-model.sh`) and unified 5-gate CPU verification (`5/5 PASS`) have been run; the full 70-task suite has not yet been run on CPU.

## Release boundary

- v4 names the current seven-layer Clover AI system.
- Observe is the next experiment, not an eighth layer added to v4.
- Observe explores reciprocal observation and change between participating systems, then extends that experiment toward internet-wide access to shared learnings, distributed memory, model resources, and compute.
- Observe begins with proof of correctness and interaction, not a latency target. Performance is measured, but time is not an initial pass/fail constraint.
- Experimental hypotheses must remain distinguishable from implemented capabilities and verified outcomes.
